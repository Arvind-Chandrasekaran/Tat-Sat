# Labels of a Related Content

Content Window Opens up when you click on a content. 

The upper part of the content window = Main Content

The lower part of the content window (underpost region) = Related Content 

Each related content has the following labels types. These labels types can be used to present the related content in classes for easy consumption. 

## 1. Sourcing Approach Label

1. Comments 
2. Replies 
3. Links 
    1. Hidden Replies (tag a post but not visible)
    2. Semantic Textual Similarity 
    3. High Impact Account within SimCluster

## 2. “Discourse Relationship with Main Content” Label

These classes enhance the post consumption experience. 

1. **EXPANSION**: Broadens the scope or applies the concept to a new domain.
2. **CORROBORATION**: Provides specific evidence, data, or proof to support the source. (Distinguishes "agreement" from "proof").
3. **CHALLENGE**: Direct disagreement with the core premise.
4. **NUANCE**: Doesn't disagree, but adds constraints, edge cases, or "Yes,
but..." qualifications. This is the hallmark of high IQ discourse.
5. **SYNTHESIS**: Combines the source with another concept to create a *new* idea. This utilizes the AI's ability to see connections.
6. **PREREQUISITE**: Foundational knowledge required to understand the source.

## 3. Topic Label (innate trait)

Serves a similar purpose to hashtags in twitter. (when user writes a hashtag, we suggest these topics with a topics window; they can write anything they want, but joining and existing topic increases visibility). 

Write your own topic (smaller the better)

Suggested topics are from existing cluster labels of lv1 lvl2 lvl3 topics (all three unionised)

We create a better hashtag culture by providing these topics to choose from. 

Sometimes twitter hashtags be too specific or meaningless.
